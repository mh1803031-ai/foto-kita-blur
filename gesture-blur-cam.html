Catatan penting (untuk kamu, pemilik halaman):
1. Buat folder bernama audio tepat di sebelah file HTML ini.
2. Taruh file audio kamu di dalamnya dengan nama persis track.mp3 — pastikan itu audio yang memang legal untuk kamu bagikan (rekaman sendiri, lisensi resmi, atau royalty-free).
3. Timing sudah dikunci di kode ke 38.5 detik – 53 detik dan tidak muncul sebagai kolom yang bisa diedit di tampilan pengunjung. Kalau mau ubah, cari LOCKED_START / LOCKED_END di bagian <script>.
3b. Audio tidak disediakan sebagai file terpisah untuk diunduh — begitu tombol Record ditekan, audio otomatis diputar dari detik 38.5 dan langsung ikut terekam menyatu ke dalam video hasil (bukan file terpisah).
4. Struktur folder saat upload ke hosting (GitHub Pages / Netlify / dsb):
  index.html (file ini)
  audio/track.mp3

Deteksi tangan berjalan sepenuhnya di browser pengunjung (tidak diunggah ke server manapun). Butuh koneksi internet untuk memuat library deteksi tangan (MediaPipe) saat pertama kali dibuka, dan buka file ini lewat server (bukan langsung dobel-klik) supaya kamera dan file audio lokal bisa diakses dengan benar.
